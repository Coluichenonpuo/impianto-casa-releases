# Impianto casa — installer

Qui ci sono solo gli installer per Windows di **Impianto casa** (il codice è in un repo privato).

- Prima installazione: scarica `Impianto-casa-Setup-x.y.z.exe` dall'ultima release in **Releases**.
- Poi il programma si aggiorna da solo: all'avvio controlla questa pagina e installa la versione nuova alla chiusura.

Il programma non è firmato digitalmente: la prima volta Windows SmartScreen chiede conferma
("Ulteriori informazioni" → "Esegui comunque").
